# Portal Web Admin — React + Vite

## Historia de este sprint
- US-43: Formulario "Crear docente" — Daniela

## Cómo levantarlo
1. Entrar a la carpeta: `cd web-portal/admin`
2. Instalar dependencias: `npm install`
3. Iniciar el servidor de desarrollo: `npm run dev`
4. Abrir http://localhost:5173

## Requisitos
- Node.js LTS
- API del módulo Admin (Django) en http://127.0.0.1:8000 (se conecta en la Tarea 6)

## Estructura
- `src/CrearDocente.jsx`: formulario con validaciones en el cliente
- `docs/`: mockup y capturas de evidencia
