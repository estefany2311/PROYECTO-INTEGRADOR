## Historia de este sprint

## Cómo levantarlo
1. Crear el proyecto en Android Studio: Empty Activity, Kotlin, arquitectura MVVM.
2. Agregar en build.gradle: Retrofit, Coil (o Glide) y corrutinas.
3. Configurar la URL base de backend/usuario en un archivo de constantes.
